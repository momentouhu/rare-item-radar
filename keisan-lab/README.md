# けいさんラボ

**サイト: https://momentouhu.github.io/keisan-lab/**

手取り計算・年齢早見表・和暦西暦変換・住宅ローン返済額など、暮らしの「ちょっと計算したい」に特化した
無料の計算ツール＆早見表サイト。**目標: 年度内（2027年3月）に月間10万PV**。

サーバー不要・運用コスト0円。Astro で静的生成し、GitHub Actions が GitHub Pages に配信する。

---

## なぜこのテーマか（10万PVへの戦略）

「年収450万 手取り」「1985年生まれ 何歳」「昭和60年 西暦」「3000万 住宅ローン 月々」のような
**数字入りロングテール検索**は、

- 日本国内の検索ボリュームが非常に大きく、季節変動が小さい（年齢・和暦は1月と4月に跳ねる）
- 検索者が求める答えが明確で、計算で機械的に正確なページを量産できる（**プログラマティックSEO**）
- 1ページの平均滞在は短いが、「近い年収」「同じ年の和暦」など内部リンクで回遊が生まれる

という特徴があり、新規ドメインでも数百ページ単位で網羅すれば半年でロングテールの合算が積み上がる。

## 仕組み

```
src/lib/tax.ts      手取り計算エンジン（2026年度 協会けんぽ・厚生年金・雇用保険、令和8年分 所得税・住民税）
src/lib/wareki.ts   和暦・干支・年齢・学年・厄年・長寿祝い
src/lib/loan.ts     元利均等 / 元金均等
src/lib/ranges.ts   静的生成する数値の範囲（ここを広げるとページが増える）
src/pages/**        Astro ページ。[amount].astro などが getStaticPaths で量産する
.github/workflows/deploy.yml   main への push と毎週月曜に自動ビルド＆デプロイ
```

- 計算ツールはブラウザ内 JS で動く（入力データはサーバーに送られない）
- 各ページに canonical / OGP / BreadcrumbList / FAQPage の JSON-LD、`sitemap-index.xml`、`robots.txt` を出力
- 年齢は基準年（`BASE_YEAR`）で静的生成し、クライアント JS で今日の日付に補正。毎週の自動再ビルドで年跨ぎにも追従

## セットアップ

```bash
npm install
npm run dev      # http://localhost:4321/keisan-lab/
npm run build    # dist/ に静的出力
npm run preview
```

### GitHub Pages を有効にする（初回のみ）

**Settings → Pages → Build and deployment → Source: GitHub Actions**

以後 `main` に push すると自動でデプロイされる。

### 任意設定（Settings → Secrets and variables → Actions → **Variables**）

| 変数名 | 用途 |
|---|---|
| `GA_ID` | Google アナリティクス4 の測定ID（`G-XXXXXXXX`）。設定すると計測タグが入る |
| `ADSENSE_CLIENT` | AdSense のパブリッシャーID（`ca-pub-...`）。設定すると広告枠が有効になる |
| `ADSENSE_SLOT` | AdSense の広告ユニットID |
| `SITE_URL` / `BASE_PATH` | 独自ドメインに移行する場合（例: `https://keisan-lab.com` / `/`） |

## 10万PVまでのロードマップ

### 今すぐ（公開直後）
1. **Google Search Console に登録**し、`sitemap-index.xml` を送信する（最重要。インデックスが始まらないと何も起きない）
2. Bing Webmaster Tools にも登録（GSC からインポート可）
3. GA4 を設定して `GA_ID` を入れる
4. **独自ドメインの取得を強く推奨**（年1,500円程度）。`github.io` サブドメインは評価が分散しやすく、独自ドメインの方が中長期で有利。Settings → Pages → Custom domain で設定し、`SITE_URL`/`BASE_PATH` を変更するだけで移行できる

### 1〜2か月目（インデックス獲得期）
- GSC の「ページのインデックス登録」を見て、除外されたページのタイトル・本文の差別化を進める
- 検索流入が出始めたクラスタ（おそらく年齢・和暦から）に解説記事を追加して厚みを出す
- ページ追加候補（`src/lib/ranges.ts` と `pages/` を増やすだけ）:
  - 時給別 年収・手取り（`/tedori/jikyu/{円}/`）、ボーナス手取り、年収別 所得税・住民税
  - 「〇〇日後は何日？」「〇〇年〇月〇日から今日まで何日」日数計算
  - 年収別 家賃目安・ふるさと納税上限（YMYL だが検索意図が明確で相性が良い）

### 3〜6か月目（拡大期）
- GSC の検索クエリから「表示はあるが順位が低い」ページを見つけてリライト
- X / Threads に「年収別手取り一覧」などの画像投稿で被リンク・指名検索を作る
- 1月（年齢早見表・干支）、3〜4月（新年度の料率・新社会人の手取り）、6月（住民税決定）、12月（年末調整）の季節需要に合わせて更新記事を出す
- AdSense 審査に通ったら広告枠を有効化（`ADSENSE_CLIENT`）

## 計算の前提・出典

- 健康保険料率: 協会けんぽ 東京都 9.85%、介護保険 1.62%（2026年度）
- 厚生年金 18.3%、雇用保険 労働者負担 0.5%（2026年度、一般の事業）
- 所得税: 令和8年分（基礎控除 58万円＋所得に応じた上乗せ、給与所得控除の最低保障 65万円）、復興特別所得税 2.1%
- 住民税: 所得割 10%、均等割 5,000円＋森林環境税 1,000円、基礎控除 43万円、調整控除
- 想定: 独身・扶養なし・賞与なし（賞与ありは別途表示）。標準報酬月額の等級表にあてはめて計算

年度が変わったら `src/lib/tax.ts` の `RATES` と控除関数、`src/lib/site.ts` の `BASE_YEAR` / `TAX_YEAR_LABEL` を更新する。
